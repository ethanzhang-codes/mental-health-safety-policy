# Choosing a license

No license has been applied automatically because licensing is an owner decision.

Common options include:

- **MIT:** short and permissive; allows reuse with attribution and warranty disclaimer.
- **Apache-2.0:** permissive and includes an explicit patent grant.
- **GPL-3.0:** requires distributed derivative code to remain under the GPL.
- **No license:** others may view the repository but generally do not receive permission to copy, modify, or redistribute it.

For a research-code release intended for broad reuse, Apache-2.0 or MIT are common choices. Dataset licenses are separate: a code license does not grant permission to redistribute datasets, model weights, or third-party content.

After choosing, add the complete standard license text as a root-level file named `LICENSE` and replace the License section in `README.md`.
